START WITH A JOB THAT FITS

Weekly updates that keep coming back.

For agency operators moving approved updates from a spreadsheet into a client portal. Start with one repeatable path in one tab, a unique record ID, and a visible saved result. Use an existing bulk import if it already solves the job.

FIRST USE

Teach one. Check one. Then repeat.

New to Mimic? Open the app and click See it actually work to run the included reading-form exercise first.

  1. 1

    Start with a test record.

    Sign in to your portal. Choose Teach a task and name it “Weekly client status.” Start recording from a page you can return to for each update.

  2. 2

    Show the complete update.

    Find a record by its unique ID, change its status and note, and save. Choose Pick success and select the result containing the record ID and new status. Finish and save the task.

  3. 3

    Try a different record.

    Use Run once with different inputs. Inspect the actual portal and make sure the right record changed. Review the expected text in Task details; a generic “Saved” message is too weak.

  4. 4

    Give it three rows.

    Choose Run a list, upload your CSV, and map its columns to your task’s inputs. Review the batch, start it, and complete any checkpoints. Inspect uncertain rows before continuing.

KNOW WHAT TO EXPECT

Your browser stays in the loop.

Keep Chrome open. Tasks and spreadsheet contents stay in this Chrome profile. A “Verified” row means your selected visible check passed; inspect the website when anything is uncertain.

Start with single-tab forms. Work across tabs, embedded frames, uploads, drag-and-drop, CAPTCHA, cloud scheduling, and shared team libraries is outside this first offer. Each customer portal needs its own trial.

Free currently includes three custom tasks and three rows per list. Paid checkout and Chrome Web Store publication are still being prepared.
